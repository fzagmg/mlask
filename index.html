Routing otomatis antar-VPS • Kode ke Hermes (VPS 3), gambar ke VPS 2 • Foto otomatis dikompres ≤ 1024px.

Konfigurasi Multi-URL & Model Ollama

Default same-origin: /api/route. Pesan dioper otomatis: kode ke VPS 3 (Hermes), gambar dibaca VPS 2, suara lewat VPS 2 lalu VPS 3, obrolan ke VPS 1. Jika router tidak terjangkau, chat otomatis memakai Ollama cadangan di bawah.

Kontrak API router (untuk pembuat backend) 
POST {URL router}  (JSON)
{
  "mode": "auto",
  "session": "chat_...",
  "stream": true,
  "prompt": "pesan terakhir pengguna",
  "images": ["base64", ...],
  "history": [{ "role", "content" }],
  "intent": { "has_images", "image_gen", "image_edit",
              "image_read", "tts" },
  "vps": { "vps1": { "url", "model" },
           "vps2": { "url", "model" },
           "vps3": { "url", "model" },
           "coder": = vps1, "vision": = vps2,
           "hermes": = vps3 },
  "numCtx": 8192, "systemPrompt": "...",
  "options": { "num_ctx": 8192 },
  "hints": { "handoff_marker": "[OPER_VPS2]", ... }
}
Ping:  {"ping": true}  -> balas HTTP 200

Respons: NDJSON (1 JSON per baris) atau JSON tunggal
{"progress": "teks status langkah"}
{"trace": {"label":"VPS 2","model":"...","ms":900,"note":"..."}}
{"message": {"content": "teks"}}   atau   {"reply": "teks"}
{"audioUrl": "url | data-url | base64"}
{"generatedImages": ["url | data-url | base64"]}
{"error": "pesan"}
- trace objek = tambah 1 langkah; trace array = ganti semua
- router tidak tersedia (gagal / HTTP 404, 405, 501):
  chat otomatis memakai Ollama cadangan
Cadangan: Ollama langsung (otomatis jika router tidak terjangkau)

Pilih URL utama untuk mengecek & memuat daftar model aktif secara otomatis.

4096 token

Disarankan 4096 atau 8192 agar RAM di InstaBox tidak penuh.

Log berisi mode, jejak operan, durasi & status ke path /routing_logs; isi pesan tidak dikirim. Firebase tidak wajib. Lebih aman mengosongkan secret dan mengatur Rules database agar path tersebut boleh ditulis.

Penting jika diakses dari browser/hosting luar:

Pastikan di terminal VPS InstaBox Anda sudah menambahkan OLLAMA_ORIGINS="*" dan OLLAMA_HOST=0.0.0.0:11434 saat menjalankan ollama serve agar tidak terblokir CORS.
